# GOODIIZ - Premium Nuts & Treats Website

A modern, premium product showcase website for GOODIIZ built with Next.js, TypeScript, and Tailwind CSS.

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Open in Browser
Visit http://localhost:3000

## Project Structure

```
app/
├── components/
│   ├── Header.tsx          # Navigation header
│   └── Footer.tsx          # Footer component
├── products/
│   ├── page.tsx            # Products listing page
│   └── [id]/
│       └── page.tsx        # Product detail page
├── about/
│   └── page.tsx            # About page
├── contact/
│   └── page.tsx            # Contact page
├── lib/
│   └── products.ts         # Product data
├── layout.tsx              # Root layout
├── page.tsx                # Home page
└── globals.css             # Global styles
```
